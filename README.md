# 🗡️ Pokédex

Uma aplicação web simples e interativa que consome a [PokeAPI](https://pokeapi.co/) para listar e exibir informações sobre diferentes Pokémon. Projeto desenvolvido para praticar conceitos fundamentais do desenvolvimento web moderno.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização, layout responsivo e design dos cards.
- **JavaScript (ES6+)**: Manipulação do DOM, requisições assíncronas com `fetch` e lógica da aplicação.

## ✨ Funcionalidades

- 🔍 Busca de Pokémon por nome ou número ID.
- 🎨 Interface temática e responsiva.
- ⚡ Consumo de dados em tempo real da PokeAPI.
- 📊 Exibição de detalhes (tipos, estatísticas e imagens).
